# 🌾 AgriAdvisor

### AI-Powered Agricultural Advisory System

> **Smart agricultural guidance for farmers — through text, voice, and local languages.**

AgriAdvisor is a full-stack platform that helps farmers get practical guidance on farming, crop diseases, pests, fertilizers, soil, weather, market prices, and government schemes.

## 🚀 Live Demo

### [👉 Open AgriAdvisor](https://ai-based-agricultural-advisory-syst-liard.vercel.app/)

Create an account and start asking agriculture-related questions.

## ✨ Key Features

- 🤖 **AI Agricultural Assistant** — Get practical answers to farming-related questions.
- 🎙️ **Voice Support** — Speak to the assistant and receive voice responses.
- 🌍 **Multilingual** — Supports English and multiple Indian languages.
- 📷 **Crop Disease Detection** — Upload a crop/leaf image for disease-related analysis.
- 🌦️ **Weather Information** — Check current weather and forecasts.
- 📈 **Market Prices** — Access agricultural market-price information.
- 🏛️ **Government Schemes** — Explore agriculture-related schemes and support.
- 👨‍🌾 **Farmer Profile** — Save farm and crop information for a personalized experience.
- 💬 **Chat History** — Keep conversations organized for later reference.

## 💡 What Makes It Different?

AgriAdvisor combines **AI, multilingual support, voice interaction, agricultural knowledge retrieval, and live data** into one farmer-focused application.

It is designed to make agricultural information easier to access, especially for users who prefer regional languages or voice-based interaction.

## 🛠️ Tech Stack

**Frontend:** Next.js, React, TypeScript, Tailwind CSS

**Backend:** FastAPI, Python

**AI / NLP:** LangChain, ChromaDB, Hugging Face, LLM APIs

**Voice:** Sarvam AI, Whisper, Edge TTS

**Data:** PostgreSQL / SQLite, OpenWeather, AGMARKNET

**Deployment:** Docker, Render

## 💻 Run Locally

### Backend

\`\`\`bash
cd backend
python -m venv venv
pip install -r req.txt
python -m uvicorn app:app --reload
\`\`\`

### Frontend

\`\`\`bash
cd frontend
npm install
npm run dev
\`\`\`

> Configure the required values in \`backend/.env\` using \`backend/.env.example\`.
