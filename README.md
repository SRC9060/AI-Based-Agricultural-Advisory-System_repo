# AI Based Agricultural Advisory System

### Backend
```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r req.txt
python -m uvicorn app:app  
```
Navigate to `http://localhost:8000` in Browser

### Frontend
```bash
cd frontend
npm i
npm run dev
```
Navigate to `http://localhost:3000` in Browser
